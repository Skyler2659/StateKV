## 1. Architecture & Code Changes

### 1.1 pos_shift Rewrite

Replaced the hook-based RoPE interceptor (fragile across HF versions) with a full
forward-replacement strategy (identical architecture to `modify_gpt_neox.py`):

| Approach | Status | Why |
|----------|:------:|-----|
| Hook (`_dispatch_apply_rotary`) | ❌ Abandoned | cos/sin tables only cover new tokens in HF ≥4.45 |
| Full forward replacement | ✅ Adopted | Self-generates full-cache cos/sin; works on all versions |

Key adapters added for transformers 4.46.3 compat:

- `_resolve_past_kv_layer`: handles DynamicCache passing through attention layers (HF 4.50+)
- Config-based polyfills: `num_heads`, `head_dim`, etc. read from `self.config` not `self`
- Cache return format: returns `DynamicCache.update()` when input is DynamicCache
- `rotary_emb` try/except: tries `position_ids=`, falls back to `seq_len=`

### 1.2 Attention-Weighted L1 Scoring (experimental)

Added `LAST_QUERY_STATES` shared store between `modify_llama.py` and `kv_cache.py`:

```
L1RobustKVCache._select_indices_for_layer:
  ℓ₁_score ← ‖V·R⁻¹‖₁                     (structural importance)
  attn_w   ← softmax(Q_last·V^T / √d)      (query relevance)
  final    ← ℓ₁_score × attn_w              (combined)
```

**Finding**: Q·V^T as attention proxy is weak for invisible needles (where needle and haystack
share vocabulary). Results are equivalent to pure ℓ₁ on the invisible needle benchmark.
Kept in codebase as experimental flag for future work.

### 1.3 Code Refactoring

Split 672-line `benchmark.py` into three files:

| File | Lines | Responsibility |


### 1.4 DynamicCache 4.51+ Compatibility

Added multi-layer fallback for cache format conversion across all transformers versions:

```
_to_legacy_cache:
  try: to_legacy_cache()            # HF 4.45-4.50
  try: layers[i].keys / .values     # HF 4.51+
  try: key_cache / _key_cache       # HF 4.45-4.50 fallback
```

### 1.5 New Benchmark Source

Added `--text_source long` using `wikitext-103-raw-v1` for standard long-document PPL evaluation.

### 2.2 Needle-in-Haystack — TinyLlama Chat (baseline)

```
needle_pos  recency_only   main    l1_mixed    l1 vs main
   200        27.8        24.4      19.3      l1 wins 21%
   400        31.3        26.3      24.7      l1 wins 6%
   800        29.9        27.5      29.7      main wins 8%
```

**Finding**: ℓ₁ outperforms StreamingLLM at short-to-medium retrieval distances. Performance
degrades with distance due to *candidate pool dilution*: as the haystack grows, structurally
similar distractors compete with the needle for ℓ₁ budget.

### 2.3 Needle-in-Haystack — TinyLlama Base

```
needle_pos  recency_only   main    l1_mixed    l1 vs main
   200        27.8        24.4      22.9      l1 wins 6%
   400        31.3        26.3      23.4      l1 wins 11%
   800        29.9        27.5      27.6      parity
```

**Finding**: Base model shows similar pattern — ℓ₁ advantage at moderate distances, dilution at
extreme range. Chat model's instruction-tuning may amplify attention sink effects, giving
more headroom for ℓ₁ at close range.

### 2.4 Attention-Weighted Scoring Results

Q·V^T attention weighting was tested on all three needle distances. Results were equivalent
to pure ℓ₁ (within noise). The invisible needle (same vocabulary as haystack) does not
create sufficient Q-V directional contrast for this proxy to be effective.

## 3. Issues Encountered & Resolved

| # | Issue | Root Cause | Resolution |
|---|-------|-----------|------------|
| 1 | `past_key_values` unexpected kwarg | HF 4.46 changed attn forward signature | Added `**kwargs` |
| 2 | `num_heads` not found | HF renamed `num_heads` → `num_attention_heads` | Config-based polyfill |
| 3 | DynamicCache not subscriptable | HF 4.51 removed `__getitem__` | Used `.layers` API |
| 4 | `to_legacy_cache()` missing | HF 4.51 removed method | Direct `.layers[i].keys/.values` access |
| 5 | Index out of bounds in RoPE | Native cos/sin too small (new-token-only) | Self-generate full-cache cos/sin |
| 6 | CUDA cublas error | cos/sin generated in int64 (dtype bug) | Pass float dummy tensor to `rotary_emb` |
| 7 | DynamicCache return format | Forward returned tuple, model expects Cache | `update()` and return input cache object |
| 8 | Colab RAM crash on 3B | FP32 model exceeds 12GB RAM | Add FP16 model loading |
| 9 | PG19 dataset script unsupported | HF datasets v3 removed script support | Switched to wikitext-103 |

## 4. Current Limitations

1. **Model scale**: All GPU results on 1.1B models. 3B+ requires FP16 optimization.
2. **Benchmark coverage**: Custom needle + wikitext PPL only. Missing LongBench, RULER, PG19.
3. **Attention proxy**: Q·V^T too weak for invisible needles. Real Q·K^T needed.
4. **Candidate pool dilution**: ℓ₁ advantage decays with retrieval distance.
5. **Transformers version sensitivity**: pos_shift requires full forward replacement on
   versions ≥4.45, which needs maintenance as HF evolves.
