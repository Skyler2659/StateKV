# StateKV project guide

This documentation is organized for readers who want to understand the
research contribution before inspecting implementation details or historical
artifacts.

## Recommended path

1. [Root README](../README.md) — the research question, headline result, and
   installation instructions.
2. [Final experiment index](experiments/README.md) — the complete experimental
   story and report sequence.
3. [Cheap-R2](experiments/07_cheap_r2.md) — the final method and its ablations.
4. [Benchmark results](experiments/08_benchmark_results.md) — the main table,
   paired comparisons, runtime, and workload scope.
5. [Research results](FINDINGS.md) and [design lessons](FAILURE_ANALYSIS.md) —
   the broader conclusions that shape future work.

## Technical appendices

- [`evidence/`](evidence/) contains protocols, implementation notes, search
  records, and result summaries for individual studies.
- [`evidence/tables/`](evidence/tables/) contains concise tables used by the
  earlier experimental programs.
- `results/**/report.md` remains next to each run's raw artifacts and is
  regenerated by the corresponding runner.

The appendices are supporting material, not required reading for the main
project narrative.
